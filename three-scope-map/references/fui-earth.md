# FUI Earth Preset

Use this preset for a FUI / sci-fi HUD globe with spherical China relief, geographic lights and fine orbital instrumentation. The `original` skin has blue-gray Earth and silver-white China; `amber`, `glacier` and `alert` use the photographic material described below. New Earth or administrative-3D projects without a requested style default to this family's photographic `FUI_SCENE_PRESETS.surface` pairing and terrain-glass map. Explicit 2.0, hologram or other styles take precedence; existing projects retain their style unless a replacement is requested. Also select FUI when the user's reference matches this appearance.

## Source and copy boundary

`assets/templates/fui-earth-vue/` is a complete Vue 3 + TypeScript + Vite project. `EarthView.vue` owns the shared renderer and runtime material palette. Destination variants share administrative navigation; textured variants add geographically registered relief, a fitted camera and a native Three.js HUD beneath the map. `FuiEarth.vue` extracts its orbital rings and crosshairs into a reusable, container-sized component. Keep the globe free of small external labels, satellite tags, continent cards, heading readouts, connector lines, and decorative signal badges. Do not recreate the renderer from this text or approximate it by changing the green preset's primary color.

Create a complete project in a new or empty directory:

```bash
python3 <skill>/scripts/verify_template_integrity.py --preset fui
python3 <skill>/scripts/create_map_project.py <new-project> --preset fui
cd <new-project>
npm ci
npm run dev
```

The creation script refuses a non-empty destination, copies the full preset and
its included `LICENSE`, `NOTICE`, `LICENSES/` and `THIRD_PARTY_NOTICES.md`, and does
not install dependencies or contact npm. Use Node.js `^20.19.0` or `>=22.12.0`.
Retain those notices, the upstream source URL and non-visual author attribution.

For an existing Vue app, copy the template's `src/components/map/`, `src/assets/maps/`, `src/assets/textures/`, and `src/types/geo.ts` together, preserving its bundled license notices. Keep relative imports intact. Add `vue`, `three`, `gsap`, `@lucide/vue`, `polygon-clipping` and the TypeScript/Three type dependencies from the supplied package manifest. `maplibre-gl` and `pmtiles` are retained because the destination map imports its optional 2D adapter; the default FUI path shows Earth and 3D China. The optional MapLibre adapter/provider load only for a requested initial 2D/overlay view or an explicit later switch. When switching from 3D, keep the source visible while the destination prepares; a readiness timeout retains it with a retry message. A direct 2D/overlay route does not construct the standalone 3D scene first. Fit 2D geographic bounds using container-relative padding so a small destination viewport does not inherit a dashboard's fixed 470 px side gutters. The default provider needs no credentials but uses online OpenFreeMap styles, tiles, glyphs and sprites.

The administrative adapter bundles China and Zhejiang; other provinces and deeper
city/district drilldown use `geo.datav.aliyun.com` on demand. For an offline or
internal-network project, configure provider resources and supply all required
administrative data through the adapters. Local Earth assets do not make the
default project fully offline.

For an established 2D+3D destination, keep pending drill/back feedback beside its breadcrumb instead of covering the geography with a loading box. Keep the rendered region name until the new scope has drawn, suspend hover terrain raycasts during camera motion, and measure the complete camera flight plus a post-flight settling interval. Preserve the chosen theme, material, geography and high-quality effects while reducing render submissions and scheduling retired-resource cleanup; a faster first frame alone does not establish a smooth handoff. See [map-3d-overlay.md](map-3d-overlay.md) for the shared-context ownership and measurement contract.

## Component API

`FuiEarth.vue` accepts:

- `skin: FuiEarthSkinId = 'original'`: the unchanged `original`, `amber`, `glacier`, or `alert` preset. The internal resolved ID also accepts HEX; prefer `primaryColor` when overriding a preset's color so legacy automatic material selection keeps its preset identity.
- `primaryColor?: string`: optional `#RGB` or `#RRGGBB` color override, normalized to a lowercase six-digit theme ID. It drives the Earth, HUD, CSS, classic/terrain/smooth destination materials and 2D/overlay palette without choosing a different material.
- `alert: boolean = false`: red alert takes priority over the preset, generated default and instance `primaryColor`. Clearing alert restores that instance's selected color. It does not change the selected map material.
- `showHud: boolean = true`: show or hide the Earth orbital rings and crosshairs.
- `earthPresentation: 'surface' | 'hologram' | 'hologram-hex' = 'surface'`: select the existing textured Earth, a regular fine-dot hologram, or a regular honeycomb hologram. Both holograms show land only. Palette `skin` and destination `mapPresentation` remain independent.
- `polarStyle: 'natural' | 'enhanced' = 'natural'`: photographic ice/snow by default; optional gray grading uses the same main photograph, with no separate polar texture or reveal. The original silver branch retains its validated treatment.
- `mapStyle?: 'classic' | 'terrain-glass' | 'smooth-glass'`: explicit destination material, independent of color and Earth presentation. Classic preserves its original geometry/material family; terrain glass uses geographic relief; smooth glass uses the hologram's polished, photo-free surface and provincial projections.
- `mapWave?: 'none' | 'hex' | 'grid'`: optional glass-map ground-wave override. `none` disables the pulse; hex/grid retain the existing shared timing. Classic keeps its original base-ring behavior. Leaving this prop unset preserves the legacy presentation's wave choice.
- `mapView: '3d' | '2d' | 'overlay' = '3d'`: initial destination renderer. Overlay draws geographic 3D administrative volumes inside the MapLibre scene and camera; it is not the separate 3D/2D switch or a second canvas.

Retain the destination's `3D 地图 / 2D 地图 / 2D + 3D` selector by default in normal Earth and administrative-3D integrations. Hide it only when the user explicitly requests hidden switching or a single renderer; a plain “3D map” request selects the initial view without removing the selector. It remains visible in the demo's focused `clean=1` preview and preserves the administrative path, primary color and material. A reactive `mapView` prop can drive the same switch from application controls. Explicit standalone 2D tasks do not acquire unrelated renderers. `?mode=china&view=overlay` opens the demo directly in 2D+3D; keep its existing skin or primary query parameters.

The terrain-glass face uses the photographic Earth's China surface/ridge pigment roles at its existing linear-light energy. Theme changes update those material uniforms without rebuilding the geography. Preserve the original-skin and hologram palettes, relief equations, clear coat, extrusion and selection response.
- `quality: 'high' | 'balanced' | 'low' | 'auto' = 'high'`: a performance budget forwarded through Earth, standalone maps and the shared-context overlay. High/balanced preserve the full optical recipes. Low disables map reflection and glass Bloom/MSAA, limits glass targets to1024/DPR1 and provider DPR to1. Auto uses reported memory/CPU hints rather than an adaptive frame-rate controller; see the budget table below.
- `mapPresentation: FuiMapPresentation = 'standard'`: backward-compatible combined material/wave input: `standard`, `textured-hex`, or `textured-grid`. Prefer `mapStyle`/`mapWave` for new integrations. An explicit `mapStyle` takes precedence over its material choice.
- `mapSurface: 'auto' | 'terrain' | 'hologram-glass' = 'auto'`: backward-compatible lower-level surface choice when `mapStyle` is omitted. Auto preserves the glacier + hologram pairing below; explicit smooth glass is available with any color in a non-standard presentation. `mapStyle` takes precedence.
- `initialMode: 'earth' | 'china' = 'earth'`: choose the initial scene without mounting a second map.
- `scanStyle: FuiEarthScanStyle = 'ribbon'`: `ribbon` is named **网格扫光** (legacy alias **柔光扫掠**), and `honeycomb` is **蜂窝扫描**. Both entity and hologram Earth support these scan choices; the hologram's dot/hex texture remains an independent appearance setting. `ribbon` combines the existing transparent outer sweep shell with soft moving grid detail; entity terrain also receives its continuous ground-light response. `honeycomb` reveals geographic hexagonal cells only while the sweep passes. Neither scan changes the hologram's resting emitters, China glass, static atmosphere or destination material. The original silver skin retains its established shader path.

The globe has no small external labels or cards in any skin. `data-skin` reflects the effective skin, `data-scan-style` reflects the selected scan, and `data-ready="true"` marks completion of the visible entrance. A `ready` event also marks that point. Skin changes update existing color objects and material uniforms, preserving camera orientation and user zoom, animation timeline, textures, meshes, and WebGL canvas. Crossing between original and the additional skins applies only the calibrated 7.35/7.22 baseline distance ratio; it does not reset the view. They do not rebuild the globe or rerun its entrance.

### Explicit quality budget

`quality="high"` remains the component default; standalone `VectorMap` and low-level overlay factories retain their `balanced` default. The component forwards its choice through the overlay rather than hard-coding that tier. Current budgets are:

| Tier | Earth DPR cap | Standalone map DPR cap | Reflected-camera target | Smooth glass source |
|---|---:|---:|---|---|
| high | 1.5 | 2.5 | 2048 long side, up to1.5 DPR | 2048/DPR1.5, up to4× MSAA, Bloom |
| balanced | 1.25 | 1.5 | 1024 long side, up to1.0 DPR | 2048/DPR1.5, up to4× MSAA, Bloom |
| low | 1.0 | 1.0 | disabled | 1024/DPR1, no MSAA/Bloom |

Auto resolves low for reported memory at most4 GB, balanced for at most4 CPU cores or memory at most8 GB, otherwise high. Missing hints retain high. MapLibre retains its configurable `maxPixelRatio` ceiling in high/balanced; low additionally caps provider DPR at1 without replacing its canvas or camera. Quality changes do not alter source geography, material selection or theme. These are rendering budgets, not promised frame rates or terrain-accuracy settings.

`fuiGlassCapabilities.ts` checks the real extension and a tiny owned RGBA16F color framebuffer before any PMREM or mirror is created, restoring independent draw/read/renderbuffer bindings. If float color targets are unsupported, skip PMREM generation and Reflector construction entirely; retain the map’s pigment, direct key and local glass equations without the environment lookup. Low also creates no Reflector target. A later compositor allocation downgrade retires/disables float-dependent mirrors before drawing, including the direct path. Supported high/balanced instances retain their PMREM/reflection recipe.
